# CallProtocol — AI 대리 통화 서비스

> 말하지 않아도, 전화로 소통하는 세상.
> 청각장애인·언어장애인·콜포비아처럼 전화가 어려운 사람이 **글로 요청**하면
> AI 비서가 **자연스러운 한국어 음성으로 대신 통화**하고, 사용자는 **실시간 자막**을 보며
> 언제든 **글로 개입**해 통화를 직접 통제한다.

발표자료: [`발표자료/CallProtocol_발표자료_v5.pptx`](발표자료/CallProtocol_발표자료_v5.pptx) · 시연 캡처: [`ppt_캡처/병원`](ppt_캡처/병원)

## 실행 방법

사전 요구사항: **Python 3.11+** (외부 패키지 설치 불필요 — 표준 라이브러리만 사용)

```bash
python server.py
```

브라우저에서 http://localhost:8000 접속 → 데모 계정(아이디 `dongeui` / 비밀번호 `cse915`)으로 로그인 → 전화 걸기.

## 통화 엔진 (새 통화 화면 › "통화 종류·방식 바꾸기")

| 엔진 | 설명 |
|------|------|
| **실제 AI 음성** (기본) | ElevenLabs 음성 AI 에이전트와 브라우저에서 실시간 음성 통화. 자막 + 끼어들기 지원 |
| 실제 전화 (Twilio) | ElevenLabs + Twilio 로 실제 전화번호에 발신. 자막만 지원 (유료 Twilio 계정 필요) |
| 시뮬레이션 (백업) | 인터넷 없이 대본으로 동작. 음성 연결 실패 시 자동 전환 |

실제 AI 음성은 공개 설정된 ElevenLabs 에이전트에 Agent ID 로 연결하므로 API 키 없이 동작한다.
에이전트를 바꾸거나 실제 전화 모드를 쓰려면 `.env.example` 을 `.env` 로 복사해 값을 채운다 (`.env` 는 커밋하지 않는다).

## 시스템 구성

```
① 웹 앱 (server.py + web/)        요청 입력 · 실시간 자막 · 글로 끼어들기
        │  WebSocket (ElevenLabs JS SDK)
② ElevenLabs 음성 AI 에이전트      음성 인식 → AI 대화 → 한국어 음성 합성
        │  브라우저 오디오 입출력
③ 가상 오디오 케이블               VB-CABLE · VoiceMeeter 로 AI 음성을 통화 앱에 연결
        │
④ PC 카카오톡 보이스톡             실제 상대방 폰으로 통화 (받는 쪽 설치 불필요)
```

실서비스에서는 ③④ 대신 전화망 API(Twilio)로 실제 전화번호에 바로 발신한다.

### 데모용 보이스톡 연결 (Windows)

1. [VB-Audio](https://vb-audio.com) 에서 **VB-CABLE**, **VoiceMeeter** 설치 후 VoiceMeeter 실행
2. 앱 › 통화 종류·방식 바꾸기 › AI 음성 장치
   - 마이크: `Voicemeeter Out 6` / 스피커: `CABLE In 16ch`
3. PC 카카오톡 › 설정 › 통화
   - 마이크: `CABLE Output` / 스피커: `Voicemeeter Input`
4. 상대에게 보이스톡을 건 뒤, 앱에서 **네, 전화 걸기**

## 주요 기능

| 영역 | 기능 |
|------|------|
| 요청 | 전화번호·자연어 요청 입력, 통화 종류 자동 판단(병원·식당·매장·자유 요청), 부족한 정보 추가 질문 |
| 통화 전 확인 | AI가 이해한 목적·조건 표시 → 승인 후 발신 |
| 통화 방식 | AI 보조 통화(자막 + 개입) · AI 자율 통화 · 텍스트 직접 통화 |
| 실시간 자막 | 발화자 구분 자막, 상대방 "말하는 중" 표시 |
| 사용자 개입 | 통화 중 글로 지시(AI가 즉시 반영) · 문장 그대로 전달 · 통화 종료 |
| 기록 | 통화 결과 요약(통화 중 확정된 날짜·시간·인원 반영), 전체 대화 보기 |
| 예약 발신 | 원하는 시각에 자동 발신, 조회·취소 |
| 접근성 | 글자 크기, 고대비, 새 자막 강조 |

## 코드 구조

```
server.py              HTTP + WebSocket + 예약 스케줄러, .env 로드 (표준 라이브러리)
app/
  api.py               REST 핸들러 · ElevenLabs 연동(음성 설정, 실제 전화 발신, 통화 결과 저장)
  ai_engine.py         통화 종류 판단 · 정보 검증 · 시뮬레이션 · 요약
  auth.py / db.py      PBKDF2 인증, SQLite 저장
  websocket.py         RFC6455 WebSocket (시뮬레이션 통화용)
web/
  index.html · style.v8.css · app.v8.js   접근성 고려 단일 페이지 UI + ElevenLabs 음성 통화
```

## 안전 설계

- 통화 첫마디에 항상 **AI 비서임을 고지**, 사람 행세나 사용자 사칭 금지
- 주민번호·계좌·카드 등 **개인정보·결제 요청은 AI가 거절**
- 요청과 다른 조건(다른 시간 등)은 **사용자 확인 후 진행**
- API 키는 서버(`.env`)에서만 관리
